## Critical Analysis Questions

### 1. Which cloud provider offers the broadest range of services?
Amazon Web Services (AWS) offers the broadest and deepest range of cloud services, featuring over 200 fully functional services globally. Its early entry into the cloud market in 2006 gave it a significant head start in building a massive ecosystem of specialized tools for compute, storage, databases, and IoT.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure provides the best native integration with Microsoft technologies, including Windows Server, Active Directory (Entra ID), and Microsoft 365. Organizations running existing Microsoft infrastructure can easily establish hybrid setups and leverage licensing discounts through Azure Hybrid Benefit.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform (GCP) is the strongest in Artificial Intelligence, Machine Learning, and Kubernetes management. Because Google originally created Kubernetes, Google Kubernetes Engine (GKE) offers industry-leading managed container orchestration alongside powerful AI platforms like Vertex AI and custom TPUs.

### 4. Which cloud platform would you personally choose and why?
I would personally choose AWS due to its market dominance, vast community documentation, and comprehensive service ecosystem. Learning AWS provides a versatile foundation for cloud engineering, and its mature infrastructure makes it easy to find solutions and best practices for complex architectural challenges.

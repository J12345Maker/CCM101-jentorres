# Laboratory 03: Multi-Cloud Explorer

## Overview
This laboratory activity explores the core architecture, capabilities, and service models of the top three global cloud service providers: **Amazon Web Services (AWS)**, **Microsoft Azure**, and **Google Cloud Platform (GCP)**. It evaluates cloud providers based on real-world enterprise requirements and links Linux environments to cloud virtual machine instances.
